# Today Do

A Flutter-based social matching app that helps users find partners for spontaneous activities. Inspired by the provided product requirements document (PRD), the project focuses on secure, real-time matching and transparent activity costs.

## Features
- Create and browse activity proposals (host/guest)
- Real-time 1:1 chat after matching
- Basic review and report system
- Cost transparency for each meeting

This repository currently contains the initial Flutter project structure. To build and run the app, install [Flutter](https://flutter.dev) and execute:

```bash
flutter pub get
flutter run
```

The app will evolve to support the PRD's MVP features.
